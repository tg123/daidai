# Branding assets

High-resolution master images used to generate the favicon and app icons.
Generated by ChatGPT image model based on the original `legacy/SourceCode/id.ico` design.

| File                         | Source                                      | Used for                                                  |
| ---------------------------- | ------------------------------------------- | --------------------------------------------------------- |
| `hd_closeup.png` (1254×1254) | tight face composition                      | current `godot/icon.*` and `public/fav.ico` |
| `hd_square.png` (1254×1254)  | full poster with title bar and forest scene | reference / share card                                    |

## Regenerating icons

From the repo root (requires Pillow):

```bash
python3 - << 'PYEOF'
from PIL import Image
import struct, io
src = Image.open("branding/hd_closeup.png").convert("RGBA")
sizes = [16, 20, 24, 32, 40, 48, 64, 96, 128, 256]
images = []
for s in sizes:
    buf = io.BytesIO()
    src.resize((s, s), Image.LANCZOS).save(buf, format="PNG", optimize=True)
    images.append((s, buf.getvalue()))
n = len(images)
header = struct.pack("<HHH", 0, 1, n)
entries = b""; offset = 6 + 16 * n
for s, d in images:
    w = 0 if s >= 256 else s
    entries += struct.pack("<BBBBHHII", w, w, 0, 0, 1, 32, len(d), offset)
    offset += len(d)
ico = header + entries + b"".join(d for _, d in images)
open("godot/icon.ico", "wb").write(ico)
open("public/fav.ico", "wb").write(ico)
src.resize((512, 512), Image.LANCZOS).save("godot/icon.png", optimize=True)
PYEOF
```
